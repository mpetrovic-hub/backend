# Archive health read brake

This Linux x86_64 bundle belongs to the existing external archive-health child. The supervisor supplies `LD_PRELOAD` only in that child's environment; the existing CRON command stays unchanged. Never add it to a global PHP, WordPress or webserver environment. Runtime policy, rollout and rollback live in the [retention runbook](../../../docs/operations/retention-runbook.md).

Ship `limit-archive-reads.c`, `limit-archive-reads.so`, `manifest.json` and `fixtures/kiwi_retention_archive_2000.sqlite` together. The manifest records source/library/fixture hashes, compiler programs, linker, SDK inputs and ABI requirements. The fixture contains generated bytes only: 1,004 pages / 4,112,384 bytes, no subscriber data.

The actual PHP/PDO child completes fixture `integrity_check` at 700/350 covered 4-KiB units/s through fresh immutable read-only connections with verified `query_only=ON`/`mmap_size=0`. Native SQL callbacks register via `sqlite3_auto_extension()` in that same PID. Exact file/VFS/PID/build, reads and elapsed time must agree within 30 seconds: at least 1,003 paced calls, equal phase work, and at least 1.35 times the duration at 350. Then target rate 700 locks. Only the private full-copy test may request 350. Each `pread`/`pread64` is split and paced per covered 4-KiB region under one monotonic mutex ledger without idle credits. Random read advice is required; bound mappings, unsupported reads, lost configuration or identity and internal faults fail closed. There is no public bypass/rate switch.

## Reproduce the bundle

Use Linux x86_64, GCC 11.4.0, Python 3, Debian package tools and binutils outside Production. `prepare-sdk.py` takes one absolute private sysroot path and creates its package cache beside it. It verifies pinned HTTPS package SHA-256/version from `sdk-inputs.json` and extracts them without replacing host libraries.

```sh
python3 tools/database/archive-health-read-brake/prepare-sdk.py /ABSOLUTE/PRIVATE/sdk
python3 tools/database/archive-health-read-brake/build-fixture.py
sh tools/database/archive-health-read-brake/build-compat.sh /ABSOLUTE/PRIVATE/sdk
cp tools/database/archive-health-read-brake/limit-archive-reads.so /ABSOLUTE/PRIVATE/first-build.so
sh tools/database/archive-health-read-brake/build-compat.sh /ABSOLUTE/PRIVATE/sdk
cmp /ABSOLUTE/PRIVATE/first-build.so tools/database/archive-health-read-brake/limit-archive-reads.so
readelf -V tools/database/archive-health-read-brake/limit-archive-reads.so
readelf -d tools/database/archive-health-read-brake/limit-archive-reads.so
```

Required dependencies: `libsqlite3.so.0`, `libdl.so.2`, `libpthread.so.0`, `libc.so.6`; GLIBC symbol versions at most 2.17; no RPATH/RUNPATH. Verify every manifest hash, including the fixture, before rollout. At runtime PHP checks source/library/manifest and fixture identity/size, then uses paced PDO fixture reads. It does not add an unpaced whole-fixture hash/copy to every CRON start.
