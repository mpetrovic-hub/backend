# Domain docs

Dieses Repo nutzt eine gemeinsame Domain-Dokumentation.

Vor fachlicher Arbeit: Begriffe in `GLOSSARY.md` prüfen, über
`docs/INDEX.md` zum passenden Bereichsindex gehen und relevante Einträge
in `DECISIONS.md` sowie die dort verlinkten Fachdokumente lesen.

`CONTEXT.md` ist hier nicht die Begriffsquelle. Neue Begriffe gehören nach
`GLOSSARY.md`. Neue Architekturentscheidungen werden nur nach Klärung von
Inhalt und Ablage dokumentiert; die Dokumentationsregeln in `AGENTS.md`
gelten auch für `domain-modeling`. Fehlende ADR-Dateien werden nicht
vorsorglich angelegt.
